# Política de segurança

## Como reportar uma vulnerabilidade

Não publique detalhes sensíveis em uma issue aberta. Use a opção **Report a vulnerability** na aba **Security** do repositório para enviar um relato privado.

Inclua, quando possível, a descrição do problema, os passos para reprodução, o impacto esperado e uma sugestão de correção. Não inclua credenciais, tokens ou dados pessoais reais.

## Escopo

A interface de login administrativo presente neste frontend é apenas demonstrativa e não realiza autenticação. Uma futura API deve validar autenticação e autorização no servidor; proteções somente no Angular não devem ser tratadas como controle de acesso.
